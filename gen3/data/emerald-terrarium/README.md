# Emerald paper terrarium textures

These four JPEGs are runtime artwork from the user-approved paper terrarium
preview `papier-kampf-v6.html` (2026-09-30), copied without further edits.

- `landscape.jpg`: `paper-original-compact.jpg`, the generated papercraft arena
  based on the user's reference, including trainer rock pedestals.
- `shell.jpg`: `v5-clean-shell.jpg`, the round red/ivory paper shell with the
  clasp removed from the texture so only one physical clasp is rendered.
- `floor.jpg`: `v5-floor.jpg`, the top-down paper arena floor.
- `paper.jpg`: `closed-paper.jpg`, paper grain and original clasp detail.

The renderer crops paper grain at runtime and traces landscape polygons from
`../EmeraldTerrarium.lua`. Pokémon, trainer portraits and sound are loaded from
the user's native game data, not from these images. No ROM sprites, audio,
player saves or QA screenshots are included in this directory.
