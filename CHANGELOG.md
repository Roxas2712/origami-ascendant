# 1.0.0

Public release based on tested RC133.

- Keep the diorama world active when entering Surf on supported engine versions.
- Correct MAP battle eligibility for supported Emerald maps.
- Preserve a usable native battle when a cold map cannot provide a valid MAP formation.
- Match actor color/depth render targets to the destination on Metal and OpenGL.
- Add persistent field zoom with keyboard, controller, mouse and two-finger input.
- Retain the existing world presentation, weather, lighting, Terrarium scenes and English settings from the release candidate.

See README.md for test coverage and known issues. No new audio fix or unfinished performance change is included.
